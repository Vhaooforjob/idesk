# iDesk 1.1.1

This release reduces background work and adds the window-moving and display-recovery improvements since the last published release, v1.0.0. The v1.1.0 source tag already contains those window and display features; v1.1.1 adds the performance changes below.

**macOS 14 Sonoma or later · Apple Silicon and Intel · Version 1.1.1 (build 5)**

## Performance improvements

- Hover detection now responds to mouse events instead of polling the pointer 30 times per second, with one-shot timers for showing and hiding the Desktop Line.
- Desktop previews are captured at startup, after switching desktops, and when opening the line. Idle desktops no longer trigger a screenshot and JPEG write every 20 seconds. Repeated requests within five seconds reuse the last capture, and separate displays can capture independently.
- The Settings preview pauses when its window is hidden or fully covered. Idle animation pauses when screens sleep or Reduce Motion is enabled, and Low Power Mode lowers it from 30 to 15 FPS.
- Wind timers only run for a revealed, windy line. Display-recovery polling only runs while iDesk has a display configuration to recover; unplug recovery remains available.

These changes remove unnecessary scheduled work; battery-life improvement has not been measured.

## Also included since v1.0.0

- Press **⌃⌥M** or choose **Move a Window…** in the menu bar to search application windows, select a desktop, and move and follow the window. The Desktop Line and menu bar also offer direct window moves.
- Find desktop operations under **Desktop Actions** and visual settings under **Appearance**.
- When an external-only display disconnects, iDesk restores the main display and returns to the selected external display when it reconnects. Recovery handles partial failures, and window moves are checked before switching desktops.

Window moves require Accessibility access and regular desktops on the same display. Full-screen, Split View, and windows assigned to all desktops are excluded.

## Download and upgrade

1. Download **iDesk-1.1.1-macOS-universal.dmg** or **iDesk-1.1.1-macOS-universal.zip**.
2. Quit iDesk, then replace `iDesk.app` in **Applications** with the downloaded copy. Existing settings and desktop names are retained.
3. Open iDesk from Applications. This build is signed ad hoc and is **not notarized**. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**. After an update, you may need to re-enable Accessibility and optional Screen Recording access.
4. To check the downloads, put **iDesk-1.1.1-SHA256SUMS.txt** beside both archives and run `shasum -a 256 -c iDesk-1.1.1-SHA256SUMS.txt`.

Validation: 86 automated tests passed; the optional style-image test was skipped. Universal Release packaging, archive integrity, and ad-hoc signatures are checked separately. Interactive hover and energy measurements are not covered by the automated suite.

## Tiếng Việt

Bản 1.1.1 giảm tác vụ nền: bỏ quét chuột 30 lần/giây, bỏ chụp desktop định kỳ, gộp yêu cầu chụp trùng và dừng animation/timer khi không cần. Low Power Mode giảm animation xuống 15 FPS. Chưa đo mức tăng thời lượng pin thực tế.

So với bản phát hành công khai 1.0.0, bản này còn có cửa sổ chuyển ứng dụng sang desktop khác (**⌃⌥M**), menu được nhóm lại, và tự khôi phục màn hình chính khi rút màn hình ngoài.

Tải DMG hoặc ZIP, thoát iDesk rồi thay app trong **Applications** và mở lại. Tên desktop và thiết lập được giữ nguyên. Bản universal hỗ trợ Apple Silicon/Intel, yêu cầu macOS 14 trở lên. App ký ad-hoc, chưa notarize; có thể cần **Open Anyway** và bật lại quyền Accessibility/Screen Recording sau cập nhật.
