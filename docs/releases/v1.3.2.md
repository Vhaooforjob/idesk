# iDesk 1.3.2

Brightness, color mode and Night Shift now follow what the screen and macOS really say, and screens that list color modes can be switched between them.

**macOS 14 Sonoma or later · Apple Silicon and Intel · Version 1.3.2 (build 11)**

## Changes since v1.3.1

| Area | v1.3.1 behavior | v1.3.2 behavior |
| --- | --- | --- |
| Values after using the screen's own buttons | The slider showed the old level until you reopened the menu or the tab, and then only one step behind | While the menu or Settings is open, iDesk reads the screen every 3 seconds; sliders, ticks and the color mode update in place. Nothing is read while they are closed |
| Screen color mode | Not shown | Screens that list color presets over DDC/CI (for example sRGB, 6500 K, 7500 K, User 1) show their current mode and can switch it, in **Settings → Screens → Color mode** and **Brightness and Color → Color Mode** |
| Night Shift | Read when the menu opened or the tab appeared | Updates as soon as it changes: Control Center, its schedule, a shortcut or System Settings |
| A color mode the screen refuses | Not applicable | A message says so and the picker goes back to the mode the screen is really in |

## How to use the changes

- **Settings → Screens:** below Brightness and Warmth, **Color mode** lists the modes the screen reports. It is hidden for screens that report none.
- **Menu bar → Brightness and Color → Color Mode** (per screen) does the same, with the current mode ticked.
- Leave the menu or Settings open while you press the screen's own buttons to see the values follow.

## Compatibility and known limitations

- Color modes come from what each screen lists over DDC/CI, and only on Apple Silicon. A screen that lists none shows no Color mode. Vendor-specific picture modes such as Game or Movie are not read unless the screen offers them as color presets.
- The first time a screen is read, listing its features takes about a second; it is kept until the Mac wakes.
- With two identical screens, iDesk cannot tell which DDC channel belongs to which, and pairs them in order. If a slider moves the other screen, tell us. Screens of different models are matched exactly. This release was tried with one external screen.
- Night Shift is still one macOS setting for every screen, and some external screens do not show it.
- Settings migrate automatically. No change to permissions.

## Validation

Automated: **215 tests, 0 failures, 2 skipped** (one needs two displays). New tests cover reading the capabilities text, unsupported features, the color mode list and its current mode, asking a screen's features only once, writing and refusing a mode, following changes made with the screen's buttons, stopping the periodic read, and Night Shift changes made elsewhere.

By hand on an Apple Silicon Mac with one external screen: its feature list and current color mode (7500 K, among sRGB, 6500 K, 7500 K, 9300 K and User 1) were read, the same mode was written back, and Night Shift change notifications arrived for both turning it on and off. Not checked by hand: switching to a different color mode, two external screens, Intel Macs, and the live updates in a finished release build.

## Download and upgrade

1. Download **iDesk-1.3.2-macOS-universal.dmg** or **iDesk-1.3.2-macOS-universal.zip**.
2. Quit iDesk, replace `iDesk.app` in **Applications**, and open it again.
3. This build is signed ad hoc and is **not notarized**. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**. Accessibility and optional Screen Recording may need to be re-enabled after upgrading.
4. Put **iDesk-1.3.2-SHA256SUMS.txt** beside both archives and run `shasum -a 256 -c iDesk-1.3.2-SHA256SUMS.txt`.

## Tiếng Việt

Bản 1.3.2 làm độ sáng, chế độ màu và Night Shift bám sát giá trị thật: khi menu hoặc cửa sổ Settings đang mở, iDesk đọc lại màn hình mỗi 3 giây nên thanh trượt tự cập nhật khi bạn bấm nút trên màn hình, và Night Shift cập nhật ngay khi đổi ở bất cứ đâu. Màn hình nào khai báo các chế độ màu qua DDC/CI (sRGB, 6500 K, 7500 K, User 1…) sẽ có mục **Chế độ màu** để xem và đổi. Hai màn hình giống hệt nhau có thể bị ghép đảo kênh DDC; bản này mới thử với một màn hình ngoài.
