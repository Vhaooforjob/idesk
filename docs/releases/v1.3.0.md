# iDesk 1.3.0

Find desktops, windows and presets in one command palette, move groups of windows with undo, and save workspaces that can restore applications and window layouts. This release also adds desktop organization, optional window rules, settings backups and GitHub update checks.

**macOS 14 Sonoma or later · Apple Silicon and Intel · Version 1.3.0 (build 9)**

## Changes since v1.2.1

| Area | v1.2.1 | v1.3.0 |
| --- | --- | --- |
| Search | Desktop search and a separate window picker | Unified command palette with desktops, windows, presets, actions, pins and recent history |
| Organization | Desktop names, colors and icons | Groups, tags, favorites, per-desktop shortcuts and privacy-aware window badges |
| Window management | Move one window with optional follow | Batch moves, picker-to-card dragging, 20-group undo history and minimized-window activation |
| Arrangement | No quick geometry controls | Halves, thirds, two-thirds, center, maximize and a 2 × 2 grid, with separate geometry undo |
| Desktop Line | Fit all desktops to the available width | Additional scrollable and grid layouts |

| Settings | Local persistence | Versioned export/import with desktop mapping, write-error reporting and retry |

| Diagnostics and updates | No built-in release checker | Operation journal, content-free diagnostic export and stable GitHub release notes |

## How to use the changes

- Press **⌃⌥S** for the command palette. Use `>` to find presets and `@` to find windows. Set desktop groups, tags, favorites, privacy and individual shortcuts in **Settings → Desktops**.
- Press **⌃⌥M** for **Find and Move Windows**. Check a batch or use **Select App Windows**, choose a destination, or drag the selection onto a valid Desktop Line card. **Go to Window** also restores minimized windows. Press **⌃⌥Z** to undo a manual move group.
- Use the picker's arrangement menu for window geometry. **Undo Arrangement** is separate from desktop-move undo. A grid accepts at most four windows per display.
- Choose the line layout and export/import settings under **Settings → General**. Backup import previews explicit desktop mappings and replaces the configuration.
- In **Settings → Presets**, save launch applications, files, folders and HTTP(S) URLs. **Remember Open Window Layout** saves eligible windows. **Edit…**, **Duplicate** and **Retry Failed Items** help maintain sessions without repeating successful restores.
- **Settings → Rules** configures app/title routing for newly discovered windows. **Settings → Workspace** provides context automation, operation results, diagnostics and **Check for Updates**. Context automation starts paused; imported window rules are disabled and imported context rules are cleared.
- The app provides **Switch Desktop**, **Apply Workspace Preset**, **Toggle Desktop Line** and **Restore Displays** actions for Apple's Shortcuts app. Switching and preset application wait for their operation result.

## Reliability improvements

Settings and existing presets migrate automatically. Failed saves can be retried. Private previews are purged from memory and disk, including pending captures. Partial batch failures keep successful moves available for undo; session retries exclude already restored windows.

Window rules use Accessibility notifications with a 15-second fallback scan. A fresh notification no longer cancels verification of a move already sent to macOS. Retrying a failed grid item retains its original cell index and recalculates geometry using current screen bounds.

## Compatibility and known limitations

- Moving windows remains limited to regular desktops on the same display. Full screen, Split View and windows pinned to all desktops are excluded. Restore minimized windows before moving or arranging them. Individual applications may reject requested geometry.
- Saved sessions restore matching windows and launch items; applications remain responsible for reopening documents. iDesk does not recreate unsaved documents or arbitrary browser tabs. Ambiguous window matches require explicit selection.
- macOS private APIs and Accessibility behavior vary across OS versions and applications. Symbol availability alone is not a compatibility guarantee. Display shutdown retains the existing timed confirmation and recovery behavior.
- Settings backups contain desktop names, shortcuts, rules, paths/URLs and saved window titles, but no preview images. Language and launch-at-login are system preferences and are not included.
- GitHub checking opens the release page for manual installation. Sparkle, an appcast and update signing are not configured, so this release does not install updates automatically.

## Validation

**165 automated tests, 0 failures, 0 skipped**, including settings migration/import, partial batch undo, session matching/retry, private preview removal, palette filtering, minimized windows, context selection, update URL/version validation and the two event/grid regressions.

UI render fixtures completed. The offscreen Settings render still emits a negative-width geometry warning. Automated tests do not establish real-window drag behavior, every third-party application's resize behavior, Shortcuts/Spotlight discovery, or physical screen sleep/reconnect behavior; these need interactive validation.

## Download and upgrade

1. Download **iDesk-1.3.0-macOS-universal.dmg** or **iDesk-1.3.0-macOS-universal.zip**.
2. Quit iDesk, replace `iDesk.app` in **Applications**, and open it again. Keep a copy of the previous app and settings if you need to roll back; older versions do not understand the new settings fields.
3. This build is signed ad hoc and is **not notarized**. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**. Accessibility and optional Screen Recording may need to be re-enabled after upgrading.
4. Put **iDesk-1.3.0-SHA256SUMS.txt** beside both archives and run `shasum -a 256 -c iDesk-1.3.0-SHA256SUMS.txt`.

## Tiếng Việt

Bản 1.3.0 mở rộng tìm kiếm thành Command Palette chung cho desktop, cửa sổ, preset và thao tác. Có nhóm/tag/yêu thích, phím tắt từng desktop, chuyển nhiều cửa sổ với undo, kéo từ picker lên thẻ desktop và xếp cửa sổ nhanh với undo riêng.

Preset lưu thêm ứng dụng, đường dẫn và bố cục cửa sổ; hỗ trợ chỉnh sửa, nhân bản, chọn lại cửa sổ khớp và chỉ thử lại mục lỗi. Có rule cửa sổ, context automation mặc định tạm dừng, bốn App Shortcuts, backup/import cấu hình, ẩn preview theo desktop, nhật ký thao tác và kiểm tra bản mới qua GitHub.

Đã sửa lỗi sự kiện mới hủy bước xác minh đang chạy và thử lại grid mất vị trí ô. **165 test đạt, không bỏ qua**. Test render Settings còn một cảnh báo kích thước âm; drag trên cửa sổ thật, discovery Shortcuts/Spotlight và sleep/reconnect cần kiểm tra tương tác.

Bản Universal hỗ trợ macOS 14 trở lên, ký ad hoc và chưa notarize. Có thể cần bật lại quyền Accessibility/Screen Recording sau nâng cấp. Cập nhật hiện tải/cài thủ công qua GitHub, chưa tự cài bằng Sparkle.
