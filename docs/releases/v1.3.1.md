# iDesk 1.3.1

Each external screen gets its own brightness and warmth sliders, with a Night Shift switch and shortcuts to brighten, dim and flip Night Shift from the keyboard.

**macOS 14 Sonoma or later · Apple Silicon and Intel · Version 1.3.1 (build 10)**

## Changes since v1.3.0

| Area | v1.3.0 behavior | v1.3.1 behavior |
| --- | --- | --- |
| External screen brightness | Only with the screen's own buttons | **Brightness** slider per external screen. It moves the screen's real backlight over DDC/CI when the screen answers (Apple Silicon); otherwise it darkens the picture in software, never below 10% |
| Screen color | None | **Warmth** slider per external screen, a gamma tint that works on every screen |
| Night Shift | Only in System Settings | A switch in the menu bar and **Settings → Screens**. It is one macOS setting for all screens |
| Shortcuts | None for these | `⌃⌥↑` / `⌃⌥↓` change the brightness of the external screen under the pointer by 5%; `⌃⌥N` turns Night Shift on or off. All three can be changed |
| Remembering | None | Software brightness and warmth are saved per screen and come back when the screen is seen again; a backlight keeps its own level |

## How to use the changes

- **Settings → Screens:** one section per external screen with **Brightness**, **Warmth** and **Reset Colors**, then the **Night Shift** switch. The note under each section says whether the screen is dimmed in hardware or in software.
- **Menu bar → Brightness and Color:** the same sliders and Night Shift switch.
- **Settings → General → Shortcuts:** *Brighten / Dim the screen under the pointer* and *Turn Night Shift on or off*. If the pointer is on the built-in screen, the first external screen changes.

## Compatibility and known limitations

- DDC/CI and Night Shift use private macOS calls, looked up at runtime. If macOS removes them, brightness falls back to software dimming and the Night Shift switch is hidden. These private calls are also why iDesk is not on the Mac App Store.
- DDC/CI works on Apple Silicon only. Some cables, docks and the HDMI port of some Apple Silicon Macs do not pass it through; those screens get software dimming. On Intel Macs every screen uses software dimming.
- Software dimming and Warmth use a gamma table, last while iDesk runs, and are given back when iDesk quits. Another app that sets the same table (for example a color temperature tool) can override them.
- Night Shift is one switch for every screen, and some external screens do not show it. Use **Warmth** to tint one screen.
- Settings migrate automatically. No change to permissions.

## Validation

Automated: **200 tests, 0 failures, 2 skipped** (one needs two displays). New tests cover the color math, DDC replies and checksums, matching screens to DDC channels, writing only the newest slider level, the fall back to software dimming, saved levels, reset, the shortcuts and Night Shift.

By hand on an Apple Silicon Mac with an external 1080p screen: the screen answered DDC/CI, its brightness was read, changed by one step and restored; a gamma tint was applied and removed; Night Shift was read, switched and restored. Not checked by hand: Intel Macs, several external screens, a DisplayLink dock, and the sliders in a finished release build.

## Download and upgrade

1. Download **iDesk-1.3.1-macOS-universal.dmg** or **iDesk-1.3.1-macOS-universal.zip**.
2. Quit iDesk, replace `iDesk.app` in **Applications**, and open it again.
3. This build is signed ad hoc and is **not notarized**. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**. Accessibility and optional Screen Recording may need to be re-enabled after upgrading.
4. Put **iDesk-1.3.1-SHA256SUMS.txt** beside both archives and run `shasum -a 256 -c iDesk-1.3.1-SHA256SUMS.txt`.

## Tiếng Việt

Bản 1.3.1 thêm thanh trượt **độ sáng** và **độ ấm màu** cho từng màn hình ngoài (Settings → Screens và menu bar → Brightness and Color), công tắc **Night Shift**, và phím tắt: `⌃⌥↑` / `⌃⌥↓` tăng/giảm độ sáng màn hình ngoài đang trỏ chuột, `⌃⌥N` bật/tắt Night Shift. Độ sáng chỉnh đèn nền thật của màn hình (DDC/CI, chỉ Apple Silicon) khi màn hình hỗ trợ, nếu không thì iDesk làm tối hình bằng phần mềm. Night Shift là cài đặt chung cho mọi màn hình; muốn ấm màu riêng một màn hình thì dùng thanh Độ ấm màu.
