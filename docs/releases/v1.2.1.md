# iDesk 1.2.1

The menu bar icon and desktop name use the colors macOS chooses again, long names no longer crowd the menu bar, and iDesk is safer with damaged settings and failed desktop switches.

**macOS 14 Sonoma or later · Apple Silicon and Intel · Version 1.2.1 (build 8)**

## Changes since v1.2.0

| Area | v1.2.0 behavior | v1.2.1 behavior |
| --- | --- | --- |
| Menu bar colors | The icon and desktop name took the desktop's color, so they could be unreadable (black on a light-text menu bar) | They use the color macOS chooses for the menu bar and its highlight state; the desktop's own color stays in the menu, line, search and banner |
| Long desktop names | Any length, which could push the item into the notch or over other icons | Cut to 24 characters with "…"; hover for the full name |
| VoiceOver | Read "iDesk" | Reads "iDesk, <desktop name>" |
| Damaged `settings.json` | Replaced by defaults on the next save, losing desktop names | Kept as `settings.json.bak` beside the new file |
| Switch that never arrives | Nothing happened and nothing was said | A message names the desktop and the likely cause |
| Idle power | Desktops re-read every two seconds, also while screens sleep | Re-read pauses while screens sleep and catches up on wake |
| Shortcut keys | `-`, `` ` ``, arrows, Tab and Return could not be used | They can be typed or recorded |
| Shortcuts macOS uses | Could be set, and would answer iDesk's own key presses | Rejected with a message |
| Saving previews | Encoded and written on the main thread | Written in the background |

## How to use the changes

- **Menu bar tooltip:** rest the pointer on the iDesk item to see the full desktop name, also when the item shows only the icon.
- **Settings → General → Shortcuts:** click a shortcut and press a modifier with `-`, `` ` ``, an arrow, Tab or Return. Written by hand, they are `⌃⌥-`, `⌃⌥←`, `ctrl+option+tab` and so on. A shortcut that macOS uses to switch desktops, such as ⌃← or ⌃1 when those are on, shows "macOS uses this shortcut to switch desktops".
- **Damaged settings:** if iDesk cannot read `~/Library/Application Support/iDesk/settings.json`, it starts with defaults and keeps the old file as `settings.json.bak`. Rename it back after quitting iDesk to recover your names.
- **Failed switch:** if the desktop is not current 2.5 seconds after a direct shortcut (5.5 seconds when walking with ⌃← / ⌃→), iDesk says macOS did not change desktops and suggests checking the Mission Control shortcuts and the screen.

## Compatibility and known limitations

- The failed-switch message also appears if you move to another desktop yourself during that wait.
- Arrow keys in menu items are not shown as menu hints; the shortcuts still work.
- Settings migrate automatically. No change to permissions.

## Validation

Automated: **128 tests, 0 failures, 2 skipped** (one needs two displays). New tests cover the unmodified menu bar tint and template icon, truncation, tooltip and VoiceOver label, the settings backup, switch failure reporting, polling pause and resume, the new shortcut keys, reserved shortcuts, and clearing previews while a background write is queued. The release package was built universal and checked after extraction. Not checked by hand: a physical screen sleep and wake cycle, and the menu bar over every wallpaper and light/dark combination.

## Download and upgrade

1. Download **iDesk-1.2.1-macOS-universal.dmg** or **iDesk-1.2.1-macOS-universal.zip**.
2. Quit iDesk, replace `iDesk.app` in **Applications**, and open it again.
3. This build is signed ad hoc and is **not notarized**. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**. Accessibility and optional Screen Recording may need to be re-enabled after upgrading.
4. Put **iDesk-1.2.1-SHA256SUMS.txt** beside both archives and run `shasum -a 256 -c iDesk-1.2.1-SHA256SUMS.txt`.

## Tiếng Việt

Bản 1.2.1 sửa lỗi icon và tên desktop trên menu bar bị đổi màu theo desktop (có thể thành chữ đen trên nền tối); giờ macOS tự chọn màu. Màu riêng của desktop vẫn dùng trong menu, line, tìm kiếm và banner.

Tên desktop dài được cắt còn 24 ký tự trên menu bar, rê chuột để xem đủ tên; VoiceOver đọc cả tên desktop. File cài đặt hỏng được giữ lại thành `settings.json.bak` thay vì bị ghi đè mất tên. Nếu đổi desktop không thành công, iDesk báo kèm nguyên nhân có thể. iDesk ngừng đọc danh sách desktop mỗi 2 giây khi màn hình ngủ, và lưu ảnh xem trước ở luồng nền.

Phím tắt dùng được thêm `-`, `` ` ``, mũi tên, Tab và Return; phím tắt mà macOS dùng để chuyển desktop bị từ chối.

**128 test đạt, 2 test bỏ qua**. Chưa kiểm tra thủ công chu trình ngủ/thức của màn hình thật. Bản universal, macOS 14 trở lên; ký ad-hoc, chưa notarize.
