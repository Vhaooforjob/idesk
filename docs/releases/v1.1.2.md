# iDesk 1.1.2

This release addresses the built-in display staying dark after using **External Screen Only**, putting the Mac to sleep, and disconnecting the external screen before waking it.

**macOS 14 Sonoma or later · Apple Silicon and Intel · Version 1.1.2 (build 6)**

## Changes since v1.1.1

- Before system sleep, iDesk attempts to re-enable the screens it turned off. Automatic layout changes pause while the system or screens sleep.
- On wake, iDesk retries recovery, retaining the built-in fallback even if macOS briefly reports an incorrect active-screen state. Failed or delayed enables remain eligible for retry.
- External-only mode waits at least three seconds after wake and until recovery finishes before it can turn the fallback off again. If the selected external screen is absent, the built-in display stays on; reconnecting that screen restores the saved preference.
- Choosing another layout or **All Screens On** still cancels automatic restoration of the previous external-only choice.

Screen controls remain in the menu bar's **Screens** submenu and **Settings → Screens**. The existing **⌃⌥⌘D** shortcut turns all screens back on.

## Behavior and validation

During wake recovery, both screens may briefly be on. Layouts other than external-only that had disabled screens return to all available screens on after sleep. Display control still uses a private macOS API, so hardware behavior needs verification on the affected setup.

Automated validation: 96 tests passed, including 11 new sleep/wake regression tests. Two tests were skipped: optional style rendering and desktop capture requiring two connected displays. The physical sequence **external-only → sleep → unplug external → wake** has not yet been manually verified.

## Download and upgrade

1. Download **iDesk-1.1.2-macOS-universal.dmg** or **iDesk-1.1.2-macOS-universal.zip**.
2. Quit iDesk, replace `iDesk.app` in **Applications**, then open it again. Existing settings and desktop names are retained.
3. This build is signed ad hoc and is **not notarized**. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**. You may need to re-enable Accessibility and optional Screen Recording access after updating.
4. Put **iDesk-1.1.2-SHA256SUMS.txt** beside both archives and run `shasum -a 256 -c iDesk-1.1.2-SHA256SUMS.txt` to verify the downloads.

## Tiếng Việt

Bản 1.1.2 sửa phần khôi phục màn hình cho trường hợp chọn **chỉ màn phụ**, cho máy sleep rồi rút màn phụ trước khi mở máy. iDesk thử bật lại màn hình đã tắt trước khi sleep, tiếp tục thử khi thức dậy và chờ ít nhất ba giây trước khi áp dụng lại chế độ chỉ màn phụ. Nếu màn phụ không còn kết nối, màn hình máy được giữ bật; khi kết nối lại đúng màn phụ, iDesk khôi phục lựa chọn trước đó.

Hai màn hình có thể cùng sáng trong lúc khôi phục. Các bố cục khác có màn hình bị tắt sẽ trở về bật tất cả màn hình khả dụng sau sleep. Có 96 test đạt và 2 test bỏ qua; chuỗi sleep/rút màn phụ/mở máy trên phần cứng thật vẫn cần kiểm tra.

Tải DMG hoặc ZIP, thoát iDesk rồi thay app trong **Applications**. Bản universal hỗ trợ Apple Silicon/Intel, yêu cầu macOS 14 trở lên; app ký ad-hoc, chưa notarize. Phím **⌃⌥⌘D** bật lại tất cả màn hình.
