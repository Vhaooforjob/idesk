# iDesk 1.2.0

Find desktops from the keyboard, move windows without leaving your work, and save the way you use iDesk for coding, meetings and presenting.

**macOS 14 Sonoma or later · Apple Silicon and Intel · Version 1.2.0 (build 7)**

## Changes since v1.1.2

| Area | Before | Now |
| --- | --- | --- |
| Desktop navigation | Choose a card or menu item | Search by name/number with **⌃⌥S**; return to the previous desktop with **⌃⌥P** |
| Window picker | Always move and follow | Turn **Follow window** off to stay on your desktop; choose destinations with **⌘← / ⌘→** from Search |
| Shortcuts | Type shortcut notation | Click and press keys; see invalid, duplicate and registration errors |
| Desktop identity | Custom names | Custom names, colors and icons |
| Previews | Automatically captured and saved | Capture timestamps, refresh current desktops, clear cache, or keep images only in RAM |
| Workspace setup | Change individual settings | Apply built-in presets or save your current appearance with a screen arrangement |

## How to use the changes

- **Menu bar → Find Desktop…** or **⌃⌥S**: type a desktop name or number, use Up/Down, then Return. Search also matches display labels and Vietnamese names without requiring accents. Escape closes the panel. Enable full screen Spaces in General to include them in search.
- **Menu bar → Previous Desktop** or **⌃⌥P**: return to the previous Space on the display under the pointer. History starts when iDesk launches and changes only after an actual desktop switch.
- **Move a Window…** or **⌃⌥M**: choose a window and destination. Leave **Follow window** on for the existing behavior, or turn it off to move without switching desktops. This preference is remembered. Shift-click and direct menu moves continue to move and follow.
- **Settings → General → Shortcuts**: click a shortcut and press a modifier/key combination. Escape cancels, Delete clears it. iDesk shortcuts are suspended while recording. A shortcut must include Control, Option or Command; Shift alone is rejected. Duplicate shortcuts are disabled until resolved; a system registration failure appears beside the affected action.
- **Settings → Desktops**: select a color and icon for each desktop. The same identity appears on the Desktop Line, menu, search and name banner.
- **Settings → Desktops** also shows each preview's capture time and provides **Refresh Current Previews** and **Clear Preview Cache**. Clearing rejects any capture already in flight. Normal future captures can repopulate the cache.
- **Settings → General → Preview Storage**: turn off **Save previews on disk** to delete saved preview images and retain subsequent captures only in RAM. Capture still requires Screen Recording permission.
- **Settings → Presets**, or **Menu bar → Presets**: use Coding, Meeting or Presenting. Save your current Look and Desktop Line settings with no screen change, all screens, main only, or one selected external screen. Saved external screens are matched by stable display identity. If that screen is unavailable, the preset does not apply. A rejected or timed-out display change also leaves appearance unchanged.

Presets do not replace desktop names, colors/icons, shortcuts or the preview storage policy. They apply when selected, not automatically at launch. Coding uses still cards and a pill banner. Meeting hides the line and banner and disables previews. Presenting additionally disables the switch effect and turns all screens on.

## Validation and limits

Automated validation: **112 tests passed with no skips**, including UI renders of all six hanging styles and the search, picker, desktop settings and preset panels. Coverage includes settings migration, Vietnamese search, previous-desktop history, destination navigation, moving without following, duplicate shortcuts, memory-only previews, forced refresh, clearing during capture, and canceled or unavailable preset screen arrangements.

Window moves still require Accessibility access and regular desktops on the same display. Previews can only be refreshed for currently visible desktops. Display control and window movement still rely on private macOS APIs; physical sleep/unplug/wake behavior and every monitor configuration have not been manually revalidated for this release.

## Download and upgrade

1. Download **iDesk-1.2.0-macOS-universal.dmg** or **iDesk-1.2.0-macOS-universal.zip**.
2. Quit iDesk, replace `iDesk.app` in **Applications**, and open it again. Existing desktop names and settings migrate automatically.
3. This build is signed ad hoc and is **not notarized**. If macOS blocks it, use **System Settings → Privacy & Security → Open Anyway**. Accessibility and optional Screen Recording may need to be re-enabled after upgrading.
4. Put **iDesk-1.2.0-SHA256SUMS.txt** beside both archives and run `shasum -a 256 -c iDesk-1.2.0-SHA256SUMS.txt`.

## Tiếng Việt

Bản 1.2.0 bổ sung tìm desktop bằng **⌃⌥S**, trở về desktop vừa dùng bằng **⌃⌥P**, di chuyển cửa sổ mà không chuyển theo, và chọn desktop đích bằng **⌘← / ⌘→** trong ô tìm kiếm của picker.

Bạn có thể ghi phím tắt trực tiếp, xem lỗi trùng/không đăng ký được, chọn màu và biểu tượng cho desktop, xem thời điểm chụp preview, chụp lại desktop hiện tại, xóa cache hoặc chỉ giữ ảnh trong RAM.

Tab **Cấu hình nhanh** có Lập trình, Họp, Trình chiếu và cho lưu cấu hình riêng kèm lựa chọn màn hình. Màn hình ngoài được ghi nhớ theo định danh ổn định; nếu không kết nối thì không áp dụng cấu hình. Thay đổi tắt màn hình vẫn cần xác nhận trong 15 giây, nếu hủy thì giữ nguyên giao diện.

**112 test đạt, không bỏ qua test nào**, gồm kiểm thử logic và render giao diện. Chưa kiểm tra thủ công lại mọi cấu hình màn hình và chuỗi sleep/rút màn hình/thức dậy. Bản universal hỗ trợ Apple Silicon/Intel, yêu cầu macOS 14 trở lên; ký ad-hoc, chưa notarize.
